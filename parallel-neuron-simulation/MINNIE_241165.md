# Minnie with the original model family

The subsequent [Minnie-driven experiment with inhibitory outputs](MINNIE_241165_EI.md) keeps these electrical parameters and uses Minnie's presynaptic E/I labels to set synaptic polarity. This report records the earlier all-excitatory reference.

The 1,352-neuron Minnie column now runs with the **published ModelDB 241165 regional parameters**, as requested. This replaces the M1 electrical model for this experiment. It is an adaptation of the supplied Python script using the public reference, not an exact reproduction of its missing custom mechanism files.

## Which model is used

The source is [Aberra, Peterchev and Grill (2018), ModelDB 241165](https://modeldb.science/241165), pinned to commit `93e01d4a927ab0cc5ca137329b86925777e63f02`. The unchanged `cACint209_biophys` HOC procedure assigns shared channel mechanisms and regional parameters directly to each reconstructed tree. All vendored source checksums are verified before running.

This published L4 basket-cell profile matches the supplied script's passive regional settings: axon/soma/dendrite reversal potentials of −64.601696/−69.781406/−63.118492 mV, with leak densities of 6.3e−5/2e−5/1e−6 S/cm². Example active parameters are axonal `gNaTa_tbar=3.993125` and somatic `gNaTs2_tbar=0.395881 S/cm²`. Distance-dependent `Ih` is evaluated by the upstream HOC code on the actual branches, including its endpoint-assignment behavior.

Following the original single-`Cell` design, **the same profile is applied to every neuron**, regardless of its anatomical class. It is not a calibrated collection of V1 cell-type models. No synthetic myelination, adult-rat geometry scaling, or axon replacement is applied. No external field is used; inactive `xtra`/`extracellular` mechanisms are omitted.

## Geometry, synapses, and protocol

The experiment retains the [same individual Minnie reconstructions and observed graph](MINNIE_COLUMN.md): 1,352 cells, 156,468 sections, and 124,341 anatomical contacts. The original script's discretization rule—`d_lambda=0.01` at 100 Hz, followed by `3**2` reduction and an odd segment count—produces **525,498 electrical compartments** with these regional passive parameters. Static zero-conductance `Nap_Et2` and axonal `K_Tst` instances are pruned using the existing validated optimization.

| Setting | Value |
| --- | --- |
| Synapse | NEURON `Exp2Syn` |
| Rise / decay | 0.5 / 3 ms |
| Conductance / delay | 0.01 µS (10 nS) / 1 ms |
| Reversal potential | 0 mV for every contact |
| Initialization / timestep | −65 mV / fixed 0.025 ms |
| Temperature | Published 34°C; the supplied wrapper did not explicitly set it |

**Every contact is excitatory, including outputs from anatomically inhibitory cells**, preserving the original `SynapseConstructor` defaults. The anatomical E/I labels remain descriptive metadata. This experiment therefore does not represent a balanced excitatory–inhibitory cortical circuit.

The aggregate wiring table lacks individual contact coordinates. Postsynaptic sites are sampled on recorded dendrites with a fixed seed; presynaptic events use the soma's upward 0 mV crossing. These differ from the supplied script's nearest-coordinate segment selection. Modeled sites are exported rather than presented as measured positions.

Two stimulus protocols share one constructed network. The original-style protocol injects one selected column neuron with 1 nA for 1 ms from time zero and runs for 25 ms. Its seed is the first cell in the longer protocol's stimulus list, rather than the wrapper's first sample cell. The longer protocol uses exactly the previous M1 run's 32 injected IDs and 0.5 nA from 10–60 ms, running for 100 ms. Each has a reinitialized zero-transmission control.

The wrapper's sample root IDs differ from this archived graph's IDs; their soma coordinates still match column neurons exactly. For example, original `864691135640672571` matches nucleus `264751`, now graph root `864691135693373631`. These identity changes do not imply that the biological cells are absent. The experiment retains the previously selected public reconstruction snapshot.

## Completed Genoa results

Construction took **209.68 s**. All four conditions used 32 native NEURON threads in one process; thread loads ranged from 16,401 to 16,481 compartments.

| Result | Original-style coupled | Its control | Longer coupled | Its control |
| --- | ---: | ---: | ---: | ---: |
| Simulated duration | 25 ms | 25 ms | 100 ms | 100 ms |
| Solve time | 7.31 s | 7.23 s | 28.97 s | 28.89 s |
| Total spikes | 1,380 | 1 | 2,681 | 50 |
| Spikes from uninjected cells | 1,378 | 0 | 2,621 | 0 |
| Spiking neurons | 1,352 | 1 | 1,352 | 32 |
| Resident RAM after simulation | 3.26 GiB | 3.26 GiB | 3.30 GiB | 3.32 GiB |

All neurons fired in both coupled conditions. At the end of the short/long runs, 1,199/600 soma voltages remained above −40 mV, versus zero in either control. This shows extensive recruitment and sustained depolarization under the original all-excitatory defaults; it does not establish realistic Minnie activity.

All recorded soma voltages and final compartment voltages were finite. Input graphs, initial soma voltages, and recording axes matched between each coupled/control pair. The longer protocol also matches the M1 anatomical graph, reconstruction manifest, injected IDs, and current timing. Its electrical model, synapse kinetics/polarity/strength/delay, initial voltages, placements, and compartment counts differ, so the response difference cannot be attributed to ion channels alone. Timings are single trials; RAM values are snapshots, not measured peaks.
